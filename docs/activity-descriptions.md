# Activity descriptions

Prepared for the 38 activities in your pasted database export. Every description is original wording under 300 characters. Prices and booking conditions stay in `price_note`.

## Run the SQL

Open `supabase/fill-activity-descriptions.sql`, copy the whole file into Supabase SQL Editor and run as `postgres`. It fills blank `public.activities.description` values using the exact UUID, name and curated source from your export. If a record is missing or its name/source has changed, the transaction aborts. Existing nonblank descriptions and all other fields are preserved. Rerunning the file is safe.

The script creates no table and changes no RLS policies. Its JSON data exists only inside an anonymous SQL block. It has not been run against your live database. The final SELECT lists the 38 records for review.
